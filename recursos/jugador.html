What Easy HUD does

It does

  • Reads your own VALORANT data through Overwolf: health, abilities, round summary.
  • Sends it to the tournament’s broadcast server so the stream can show it.
  • Reads your Riot ID from the Riot Client so the operator can find you, and joins the lobby code when the operator calls you.
  • Shows your camera on stream only if you press the camera button.
  • Opens with the Windows permission prompt (administrator). It is only so Overwolf can read VALORANT even when VALORANT itself runs as administrator; it does nothing else with it.

It never

  • Never reads your password or Riot account details.
  • Never records your screen, keyboard or microphone.
  • Never looks at your files or other programs.
  • Never turns your camera on by itself. It always starts off.
